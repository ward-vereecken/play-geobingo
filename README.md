# GeoBingo Site

Static landing page for GeoBingo, built to match the app's current base theme and button language.

## Files

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

## Open locally

Open `index.html` directly in a browser.

If you want a local server instead, from this folder you can run something like:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.
